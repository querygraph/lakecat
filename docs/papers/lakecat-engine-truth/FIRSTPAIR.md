# FirstPair Library Contract

slug: lakecat-engine-truth
shelf: querygraph
default_edition: full

This directory is a self-contained FirstPair source package for the LakeCat
paper "Getting Out of the Way: Engine Truth, Typed Governance, and the Thin
Catalog". The LakeCat repository owns its manuscript, figures, metadata, and
generated artifacts. The shared implementation and authoritative operational
rules live in `~/src/firstpair`.

The paper is a separate QueryGraph-shelf publication. It is a companion to the
systems paper in `../lakecat-catalog-foundation` and does not replace the
`lakecat` book owned by the repository-level `FIRSTPAIR.md`.
