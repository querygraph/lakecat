# FirstPair Library Contract

slug: lakecat-catalog-foundation
shelf: querygraph
default_edition: full

This directory is a self-contained FirstPair source package for the LakeCat
systems paper. The LakeCat repository owns its manuscript, figures, metadata,
and generated artifacts. The shared implementation and authoritative
operational rules live in `~/src/firstpair`.

The paper is a separate QueryGraph-shelf publication and does not replace the
`lakecat` book owned by the repository-level `FIRSTPAIR.md`.
